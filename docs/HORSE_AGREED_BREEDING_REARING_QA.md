# HORSE RANCH — 합의된 번식 압축·자동 자연 성장·방목지 반영

기준 main: `a0256b397b349d3c345866bdf3191659c84485d0`. 독립 브랜치: `work/hr-agreed-rearing-breeding-20261026`.

## 이번 합의 범위

- 새로운 교배: 임신 기본 180일, 말 ID/교배일 기준 재현 가능한 개체별 ±10일. 기존 300일 교배 기록의 예약 출산일은 그대로 둔다.
- 한 암말의 교배 간 최소 360게임일. 출산을 마친 뒤에도 곧장 반복 교배하여 연간 망아지가 과다 생산되지 않도록 한다. 이전 저장에 없는 과거 교배일은 만들어 넣지 않는다.
- 기존 게임의 1년 360일, 출생 후 실 일수 기준 성장, 2세 데뷔, 20.15 교육시설 4종, 기수·혈통·능력 상한, 경주·NPC·시장 계산을 그대로 이용한다.
- 신규 망아지의 기초 돌봄은 자동. 방목지 면적과 실제 2세 미만 어린 말의 마릿수로 수용 여건을 평가한다. 과밀 상태가 오래 이어지면 사육 준비도와 컨디션이 낮아지고 생후 1/2년차 자연 성장치 일부가 **일시적으로 유예**된다. 방목 여건을 개선하면 유예된 자연 성장치가 능력 상한까지 순차적으로 회복된다.
- 기존 발굽 상태는 매일 감소하지만 관리 회복이 없어서 장기 플레이에서 소진됐다. 별도 수동 버튼이나 반복 청구 대신 기본 사육비 범위의 자동 장제 관리를 추가했다.
- 방목지 수용 상태와 1ha 확장 버튼은 기존 **번식** 화면 하단에만 표시한다. 별도 메뉴, 어린 말별 사료/방목 버튼, 중복 저장 키는 추가하지 않는다.
- 출산 예정 부모의 일반 판매는 자마 생성이 멈추는 문제를 피하기 위해 제한한다. 기존 임신 부모도 동일하게 보호한다.

## 임시 게임 밸런스 (수치 재검토 가능)

| 항목 | 적용 |
|---|---|
| 새 임신 | 180±10일 |
| 재교배 가능 | 마지막 교배일로부터 360일 |
| 초기 방목지 | 1ha, 어린 말 2마리 수용 |
| 방목지 확장 | 1ha마다 어린 말 2마리 수용 추가, 120만 게임머니 |
| 과밀 사육 | 사육 준비도 하루 -1.5 (최저 35), 컨디션 일시 제한 |
| 정상 방목 | 사육 준비도 하루 +2 (최대 100) |
| 자연 성장 유예 | 준비도 70 미만이면 매 연령 경계에서 +3 기본 성장 중 1~2점 유예, 유전 상한 변동 없음 |
| 지연 성장 회복 | 정상 방목 + 준비도 85 이상 + 14일 경계마다 능력별 최대 +1 회복 |
| 발굽 관리 | 28게임일 간격 자동 관리 +46 (실제 장제·삭제 치료 수치가 아닌 게임 조정값) |

수용력 2마리/ha와 가격은 실제 축산 표준으로 단정하지 않은 **게임 밸런스 초안**이다. 플레이테스트 이후 사용자가 최종 결정한다.
