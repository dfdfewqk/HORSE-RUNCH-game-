# HORSE RANCH 20.5 — 레이팅·경주 출전·네임드 NPC 기초

## 범위
20.4 교배/출산/교육/훈련 및 경주 엔진을 유지한 채, 장기 게임의 경주 경쟁 기반을 추가한다.

- 새 독립 규칙 `systems/competition-rules.js`: 레이팅 초기값/출전 기준/결과별 변동/경주 상대 선택 등급.
- 실제 적용 `systems/competition-integration.js`: 출전 조건 검증, 경주 결과 1회 정산, NPC 전적 누적, UI 노출.
- 고정 레이팅 출전 기준(게임 밸런스용 가정): G3 65, G2 74, G1 82. **상위 등급 기준은 NPC 평균 능력 증가에 따라 자동 상승하지 않음**.
- 새 게임과 미래 경주 편성에 연 4회 G2를 추가(3/6/9/12월 24일 2R). 완료된 경주 일정은 변경하지 않음.
- 기존 8개 일반 NPC 목장은 저장 보존, 네임드 5목장을 추가: 그랜드 스터드 65, 블루힐 팜 40, 윈드필드 55, 노스밸리 45, 레드크라운 3(자본은 상대적으로 많음). **네임드 목장의 개체수/금액은 향후 밸런스 조정값**.
- 이미 있는 플레이어 말과 NPC 말의 능력치/유전/혈통/소유 관계는 수정하지 않고 기존 레이팅 필드를 우선한다. 신규 레이팅이 없는 말에만 현재 실력과 전적으로 초기값 설정.
- 경주 결과가 완료되면 출전마 전원의 레이팅을 조절하고, NPC 출전마의 전적을 기록. 재조회·다시 보기 시 두 번 반영되지 않게 `ratingSettled` 사용.

## 검사 및 재현
- `node --check systems/competition-rules.js` 및 `systems/competition-integration.js`: 통과
- `node tests/competition_rules.test.cjs`: 통과
- 기존 `tests/race_engine.test.cjs`, `tests/foal_education.test.cjs`: 통과(20.4 제공 테스트 파일 기준)
- 독립 Chromium 웹 문서 인라인 실행: 신규 데이터(5개 네임드), G1 참가 가능 NPC, G2 연 4회, 일반 경기 12두 출전, 경주 결과 1회 처리, 플레이어/NPC 레이팅·NPC 전적 누적, 데이터 serialize/normalize, 첫 오프닝 실제 경주, 브라우저 JS 오류 0건 확인.
- 로컬 파일 네비게이션은 관리자 정책으로 차단되어 JS/CSS 외부 파일을 소스 그대로 인라인 변환하여 시험. GitHub Pages 배포 및 실제 Windows 브라우저의 사용자 검증은 아직 별도.

## 미구현 / 후속
- 5개 네임드의 연간 성장·은퇴·폐사·세대교체·실제 자금 소비 및 경매 자동 구매.
- 일반 NPC 말의 완전한 생애주기·출전 이력 연동과 고령마 아카이브.
- 매일 5두 시장과 금요일 5두 특별 경매, 플레이어 주 1회 경매 출품 및 유찰 반환.
- 자세한 유전/근친 페널티 및 마방 확장·시설 체계.
- 경주 조건의 실제 제도적 레이팅과 통계적 밸런스 검증. 사용한 레이팅은 게임 내부 시험용 등급 기준.
