# HORSE RANCH 20.9 — 수명·자연사·혈통 보존

## 확정 설계
- 예상 수명 평균은 약 26세(사용자 요청 22~30세 범위), 대체로 22~30세, 드문 31~36세 장수마 포함.
- 밸런스 가중치: 19~21세 4%, 22~30세 88%, 31~36세 8%. 수의학적 실제 예측값이 아니라 게임용 초기 규칙.
- 수명은 말마다 한 번 정해 저장. 이전 저장의 이미 오래 산 말은 로드 시 사라지지 않도록 보호.
- 플레이어와 모든 NPC에 같은 수명 규칙을 적용하며 새해에만 한 번 검사.
- 번식 예약된 부모는 기존 출산 절차가 먼저 마무리되도록 자연사 처리를 잠시 유예.
- 자연사 후에는 보유마/경주 출전자에서 제외하고 기존 pedigreeArchive에 간결한 혈통·전적·주요 업적을 남김.
- 기존 명예의 전당 기록은 자연사로 갱신하되 G1/G2/G3 기록을 지우지 않음.
- 기록실의 생애 기록에는 마지막 12건, 상태 데이터에는 최근 20건만 남김. 총 건수는 단일 누적 숫자.
- 기존 20.7 은퇴·노화 공식과 20.8 신예마 영입, 20.4 교배 공식, 경기력·레이팅은 변경하지 않음.
