# HORSE RANCH 20.3 — 성장 데이터 기반 1차

기준: 20.2 main 커밋 d27071be46ebfddfaecc3d74c7f2a8a15f7b6295.

## 적용
- systems/horse-growth-foundation.js 독립 모듈 추가.
- 생성된 말에 기준 능력치(baseStats), 성장 적응도(growthEfficiency), 선천적 기질(innateTemperament) 저장.
- 출생(0세) 말은 birth, 게임에 생성된 성마는 generated로 능력치 측정 시점 구분.
- 기존 저장 말은 현재 능력치를 legacy-snapshot으로 보존하고 알 수 없는 출생 능력, 성장 적응도와 기질을 만들어내지 않음.
- 말 상세정보 > 능력치에서 기준/현재/상한/유전 기준과 출처 및 성장 적응도 표시.
- 기존 프로필의 기질 필드가 아직 비어 있는 신규 말만 선천적 기질 반영.
- 기존 저장 키 horse_ranch_v193, 20.1 원본, 경주 엔진, 훈련 횟수·효과, 교배 계산, 경주 결과는 변경하지 않음.

## 검사
- node --check 신규 모듈 및 게임 인라인 코드: 통과.
- node tests/horse_growth_foundation.test.cjs: 통과.
- node tests/race_engine.test.cjs: 통과.
- Chromium Playwright 독립 브라우저 컨텍스트: 신규 게임 생성, 프로필 표시, 망아지 데이터 생성, 기존 저장 호환 모의 복구, 페이지 JS 예외 0건.
- 테스트 브라우저에서 로컬 file:// 탐색이 정책 차단되어 외부 스크립트를 인라인으로 포함하는 동일 소스 기반 검사를 진행. 실제 GitHub Pages 접근/배포 검증은 별도.

## 아직 구현하지 않음
- 성장 적응도가 실제 훈련 효과에 영향을 미치는 계산.
- 어린 말 기초교육 포인트·수동/자동 교육·성마 성격 고정.
- 출생 기초 능력/잠재력/성장 특성의 새로운 교배 유전 공식과 근친교배 페널티.
- 금요일 경매, NPC 5개 목장 개편, 은퇴/폐사/레이팅 개편, 경제 밸런스.

의도적으로 데이터 기반만 추가하는 단계이며 위 기능을 구현 완료로 표시하지 않음.
