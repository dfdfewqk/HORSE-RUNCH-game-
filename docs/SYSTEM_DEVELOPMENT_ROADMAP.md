# HORSE RANCH — 시스템 중심 개발 로드맵

**기준**: HORSE RANCH 20.1 Data Foundation + 확정된 2026 오프닝  
**이번 개발본**: 20.2 Race System Foundation (시험용 버전 표기, 공식 기존 버전 번호와 독립)

## 독립 구조

```text
게임 데이터/state + 저장 horse_ranch_v193
  ├─ 목장, 경제, 달력
  ├─ 말/훈련/성장 데이터
  ├─ 번식·혈통·기수·전적
  └─ 경주 진행
       ├─ systems/race-engine.js       (순수 계산, 이미지/DOM 의존 없음)
       └─ systems/race-integration.js  (기존 20.1 저장, 상금, 전적 연결)
              └─ 현재 임시 주행 표시 (이후 3D 애니메이션 뷰어로 교체 가능)
```

## 다음 시스템 개발 우선순위

1. **경주 엔진 2단계**: 페이스 조절/진로 선택/마군 위치/추입 시점, 전법별 차이를 검증 가능한 규칙으로 정교화. 3D와 별도로 유지.
2. **육성·성장 루프**: 현재 speed/stamina/power, condition/fatigue/hoof, caps에 이미 있는 시스템을 유지하면서 성장 단계/개체 성향에 따른 차이를 연결. 수치 변경 전에 비교 테스트.
3. **말-기수 호흡**: friendship의 실질적 증가 조건/상한선/반응도를 확정한 뒤 시스템 연결. 기수 육성은 과잉 확장 금지.
4. **번식·세대 교체**: 2대 혈통 표시와 부모 ID를 유지하고, 개체별 잠재력·성장 단계·거리 적성의 유전 흐름을 장기 검증.
5. **목장 경제와 NPC**: 말 판매, 번식 비용, 경기 상금, 시장 규모, 회복 주기의 장기 밸런스.
6. **저장·테스트 강화**: 이전 버전 저장 마이그레이션, 수년 진행, 복구 경로 및 저장소 정착.
7. **3D 연결**: 엔진 결과의 프레임별 `p`(달린 거리), `v`(속도)를 3D 화면에 전송하는 독립 시각화 어댑터. 3D가 멈춰도 순위 계산·저장은 지속.

## 중요 개발 규칙

- 기존 20.1 정상 기능과 말 원본 데이터를 파괴하지 않는다.
- 말 이미지 교체와 경주 규칙 수정은 서로 다른 작업으로 관리한다.
- 룰과 엔진 변경 전에 자동 테스트에 예상 결과를 정의한다.
- 파일별 개별 커밋 및 반복 자동 배포를 하지 않는다.
- 현재 파일은 로컬 검수본이며 GitHub 배포 완료를 주장하지 않는다.
