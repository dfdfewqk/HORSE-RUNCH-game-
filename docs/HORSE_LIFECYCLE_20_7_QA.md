## 기준
- GitHub `main`: `e4fc3ca5b07e356c99563b4ef901c0bea55651ec` (20.6).
- 원본 `baseline/` 보존, 기존 `horse_ranch_v193` 저장 키 유지.
- 수정 범위: `index.html`의 기존 8세 자동 은퇴 제거 및 성마 훈련 한계 표시 수정, 독립 생애 모듈 2개 추가.
- 밸런스 숫자는 **게임 내부 시범값**이며 실제 수의학·경마 표준이 아니다.

## 구현된 노화 구조
- 플레이어·네임드 NPC·일반 NPC 경주마 모두 게임 내 1년마다 나이 반영.
- 8세 자동 은퇴 삭제. 8세부터 개체 상태에 따른 낮은 확률의 은퇴 가능성 발생.
- 11세 진입 시 속도·지구력·파워가 각각 **7~11점 단회 감소**. 개인별 변동은 말 ID로 결정, 재진입/로드 시 반복 적용 없음.
- 12세 이후는 각 능력치 **매년 1~3점 완만한 감소** (하한 40).
- 유전적 잠재력과 기존 `caps`는 수정하지 않음. 단, 11세 이후는 별도의 `effectiveCap`으로 훈련 한계 제한, 전성기 기록 능력치까지 다시 훈련할 수 없음.
- 8~10세 은퇴 확률은 낮고, 11세 이후 완만하게 높아지는 은퇴 판정. 고령 현역도 가능. 은퇴·폐사는 분리하되 **폐사 자체는 아직 미구현**.
- 나이 상승·능력 감소·은퇴는 게임 새해 진입 시 처리, 처리된 나이/연도 저장으로 중복 없음.
- 오래된 저장파일에서 이미 11세 이상인 말의 불명확한 과거 최고 능력과 노화 이력을 소급 추정하지 않음.

## 업적·기록 보존
- G1/G2/G3 우승 연도·날짜·거리, 최고 관측 레이팅, 통산 성적 및 관측 최고 능력 추적.
- 경기 결과 정산에서 1회만 기록. 재생·저장·불러오기로 추가되지 않음.
- 주요 성적이 있는 말은 은퇴 시 기록 스냅샷을 보관하고, 판매 시에도 명예의 전당 아카이브에 저장.
- 기록실의 명예의 전당에서 우승 내역 확인 가능. 목장 수용량과 별도의 경량 아카이브.
- 초기 NPC 데이터에 합성된 5승 이상이 있어도 진짜 전적 이력이 부족하면 명예의 전당으로 올리지 않음.
