# HORSE RANCH 20.12 — NPC 자율 경주 및 경주일 자동 정산

## 기능 범위
- 기존 `horse_ranch_v193` 저장 키와 기존 플레이어 경주 등록 및 수동 출전은 유지한다.
- 경주일(게임 내 매월 10일/24일)에서 **다음 날로 넘어갈 때**, 끝나지 않은 경주만 NPC 경주로 처리한다. 진입하자마자 자동으로 종료하지 않는다.
- NPC 출전 후보에 한해 기존 `eligible`, 20.5 레이팅 자격, 20.2 `HorseRanchRaceEngine.simulate` 계산을 그대로 사용한다.
- 하루 동안 동일한 NPC 말이 두 경주에 참가하지 않는다. 실제 참가 2마리 미만인 경주는 '출전마 부족'으로 마감한다.
- NPC 전적·레이팅·상위 등급 우승 업적, 20.11 목장 실적을 경주마다 1회 기록한다.
- 플레이어 말의 능력치/기수 관계/자금/전적/등록 기록/명예는 NPC 전용 경주로 절대 변경하지 않는다.
- NPC 피로/컨디션/발굽 관리: 매일 회복, 자동 경주 참가 후 소폭 악화. NPC 육성 구조에서 빠져 있었던 회복만 보완한다.
- 저장 데이터 증가를 막기 위해 NPC 시뮬레이션의 수천 개 위치 프레임을 저장하지 않고, 경주마다 결승 순위/기록 및 최근 48경기 간략 결과만 보관한다.
- 별도 서버·백그라운드 시뮬레이션이 아니라 게임 날짜 진행 시 동기적으로 처리한다.
- 이 버전은 NPC 현금 상금/기수 보너스/개별 경주 중계/진행 중 드라마 연출을 구현하지 않는다.

## 코드
- `systems/npc-auto-racing.js`: NPC 전용 필드 선정, 물리엔진 경주 완주, 순위·전적·업적·레이팅·랭킹 정산, 상태 중복 방지, 회복.
- `systems/npc-auto-racing-integration.js`: 기존 `advanceDay` 마지막 후킹, 홈/경주 메뉴 결과 UI.
- `index.html`: 위 2개 모듈을 기존 20.11 랭킹 모듈 다음에 로드.
- `tests/npc_auto_racing.test.cjs`: 날짜 처리, 하루 한 마리 한 경기, 저장 복구, 플레이어 무영향, 중복 방지.

## 주의/추후
- 출전 조건과 경주 점수·레이팅·세부 스탯 수치는 전체 밸런스 단계에서 조정할 초기값.
- 매년 경주 편성은 기존 구현대로 새로 생성되므로 전년도 레이스의 전체 결과 UI는 영구 이력 아닌 48개 간략 NPC 기록으로만 남음.
- 실제 Windows/배포 브라우저 플레이 검증은 로컬 자동화와 구분하여 보고할 것.
