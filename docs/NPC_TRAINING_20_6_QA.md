## 규칙

- 네임드 5개 목장의 성마(2세 이상~7세)만 **매월 1회** 자동 조교. 은퇴·부상·임신마 및 잠재력 상한 도달 항목은 제외.
- 플레이어와 동일한 `HorseRanchFoalEducation.trainingGain` 공통 성장 확률을 재사용. 성장 한계(`caps`) 초과 금지. **성장에 성공하지 않는 세션도 존재**.
- 기존 최상위 2개 목장(그랜드 스터드, 윈드필드)은 기본 월 1회로 느리게, 중견(블루힐, 노스밸리)은 월 2회, 부유한 신생 라이벌(레드크라운)은 월 3회 시도. 이는 *말마다 성공을 보장하지 않는 훈련 시도 수*.
- 플레이어 상위 현역 3마리 평균 레이팅이 NPC 상위 현역 3마리 평균과 8점 이내로 좁혀지면 투자 확대: 최상위/중견 월 3회, 레드크라운 월 4회.
- 실제 말의 남은 성장 폭에 따라 매 3개월(게임 4·7·10·다음 해 1월) 우선 훈련 능력을 검토. 고정 거리·각질 전문화 없이 세 능력치를 모두 훈련할 수 있음.
- 월간 자동 처리 시 상태에 `npcTraining.lastMonth`를 저장해 중복 훈련 방지, 과거 저장에 누락된 달을 소급 적용하지 않음.
- 게임 내 홈에 네임드 5개 목장 보유마 수·상위 레이팅·육성 강도·우선 능력·최근 월 결과 표시.
- 저장 크기를 억제하려고 말별 훈련 이력을 추가로 저장하지 않으며 목장별 최근 1개월 결과만 요약.

## 검사

- `node tests/npc_training.test.cjs`: 월간 한 번, 분기 변경, 접근 방식 강화, 잠재력 상한 준수, 기존 말 보존, 재로드 후 중복 방지.
- `node tests/competition_rules.test.cjs`, `tests/foal_education.test.cjs`, `tests/race_engine.test.cjs`: 회귀 테스트.

- 브라우저의 로컬 file:// 또는 GitHub Pages 실제 접근 검증은 별도이며 **Windows 실제 사용 검증 완료를 주장하지 않음**.

## 의도적으로 제외

- NPC 실제 유지비·훈련비 지출 및 매각/구매/번식/폐사. 이번 버전의 훈련비는 *월간 추정치*로만 계산하며 NPC 잔고는 변경하지 않음. 네임드 목장은 게임상 파산·소멸하지 않음.
- 일반 NPC 목장의 별도 경영 시뮬레이션. 일반 NPC 경주마의 장기 생애주기 및 훈련은 추후 단계.
- 훈련 시 단기 피로 계산은 내부 임시값이며 NPC는 영구적인 월별 피로 누적을 적용하지 않음. 해당 부분은 이후 자동 회복 시스템 통합 시 검토.
- 레이팅과 경주 결과를 조작하는 보정, 확률적 강제 승리, 무한 능력치 상승 없음.
