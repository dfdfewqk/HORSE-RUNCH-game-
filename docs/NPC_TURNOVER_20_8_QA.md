# HORSE RANCH 20.8 — NPC 연간 신예 충원 (교배·폐사 제외)

## 기준 및 범위
- GitHub main 20.7: `51742fb3db214c49a52655715cb9bb74bc666e4c`.
- 보유마·혈통·기존 경주 결과·20.7 노화/명예의 전당과 20.6 월간 훈련 유지.
- 게임 연도 교체 후 **20.7 노화 처리 다음**에 새 NPC 경주마를 소규모 영입.
- 기존 NPC/네임드 목장 추가 생성 금지. 현재 5개 네임드 + 구버전의 일반 목장 이름만 활용.
- 기존 은퇴마는 **살아 있는 개체로 계속 보유 수에 포함**; 임의 폐사·퇴출·자동 판매 없음.
- 새 말은 2~4세 신예/외부 실전마 형태로 영입; 실제 부모 혈통과 NPC 번식은 추정하지 않음.
- 초기 강호의 우수 말 보유를 보존하고 신규 말 능력 분포의 무한 상승 방지.
- 연도별 영입 수와 새 말 ID를 저장하여 **동일 연도 중복 생성 금지**.
- 네임드의 마방이 부족하면 최대 4칸 정도 소규모 자동 확장(실제 NPC 경제 지출은 이번 단계에서 미반영). 전체 보유 수는 100을 넘지 않음.
- 일반 NPC는 별도 재정/훈련 관리 없이 작은 규모로 충원하고 이름을 출전마 소속 표시로 사용.
- 홈 화면에 네임드 신규 영입 결과/현역 수/보유 수 표시.
- 새 모듈 `systems/npc-turnover.js`는 DOM 비의존, `systems/npc-turnover-integration.js`는 저장·화면 연결.

## 검사
- `node tests/npc_turnover.test.cjs`: 연간 충원, idempotency, 기존 말/보유 기록 보존, 기존 저장 재로드, 100두 상한, 임의 폐사 금지.
- 기존 20.3~20.7 테스트 5종 회귀 통과.
- 로컬 Chromium Playwright에서 연도 1→2→3 진행, 신규 NPC 소속/저장/마방 수량/홈 현황/JS 오류 0개.
- 실제 GitHub Pages 배포 화면 및 Windows 사용자 플레이는 아직 검증하지 않음.

## 미구현 및 제한
- **폐사·연령별 수명 모델과 살아 있는 말 공간 회수**, 실제 NPC 교배 및 세대별 혈통 연결, 금요일 특별 경매 구매/판매, 운영 자금 정산.
- 따라서 오래 진행하여 모든 목장이 100마리로 채워지면 이후 신규 영입이 멈춤. 이는 생존 개체 수 한도를 지키기 위한 임시 제한이며 다음 생애 단계에서 보완한다.
- 신규 영입마의 과거 경주 전적은 소규모 외부 경력 표시일 뿐 실제 이전 세계의 경주 로그까지 생성하지 않는다.
- 모든 수치와 입단 비율은 테스트용 게임 밸런스이며 현실 경마 통계라고 주장하지 않음.
