이 버전은 화면과 규칙을 갖춘 **1차 플레이테스트**이며, 모든 가격·확률은 잠정값이다.

## 실제 적용 범위

- 0~1세 월 3포인트, 2세 이상 월 4회 직접 버튼식 교육 대신, 20.15 교육 화면에서 시설 위탁(기초순치/기승/게이트/경주 전문)과 지정 기수 조교를 선택한다. 기존 유년기 교육 데이터는 파괴하지 않는다. 어린 말은 기존 자동 교육과 새 위탁 학습을 중복 지급받지 않는다.
- 출생 후 게임 내 실제 날짜 기반으로 1세 이후 교육 적격 판단. `bornAtDay`가 없는 기존 경주마는 기존 출전 자격을 유지한다.
- 14/30일 기초 순치, 14/30/60일 기승, 7/14/30일 게이트, 7/14/30일 경주 전문. 위탁 중 말은 경주 등록/출전/교배/일반판매/특별경매 출품/중복교육 불가.
- 위탁은 날짜에 따라 진행되고, 중간 문제 보고 시 완화·7일 연장(추가 등록비)·조기 복귀 가능. 응답하지 않으면 4게임일 후 완화 방식으로 자동 진행. 출발 안전은 입장/대기/출발이 충분히 익숙해지고 서로 다른 두 날짜에 검증됐을 때 충족한다. 완전 수료와 별개.
- 위탁료는 즉시 **한 번만** 차감한다. 기존 말 기본 사육비와 별개인 순수 교육료이며 기존 교육 월말 장부에 이중으로 적립하지 않는다.
- 경주일·회복을 우선하여 지정 기수는 7/14/30일 예약 기간 중 실제 기승한 날짜에만 경험 축적. 같은 기수의 중복 예약 금지. 예약 기간 자동 연장 없음.
- 부모와 조부모의 **관찰된** 5개 기질을 반영하여 신규 자마의 성격 생성. 조상 자료 누락은 중립적 개체차로 대체하며 허위 혈통 데이터를 기록하지 않는다. 기존 성마는 기록된 `innateTemperament`를 제한적으로 해석하여 행동 모델을 활성화하되 `legacy-observed-not-pedigree`로 출처 표기.
- 기수별 숨은 궁합·상한·관찰 횟수·양/음성 경험·드문 개선 저장. 무조건 증가하지 않음. 유전 기질은 변하지 않음.
- 직접 속도·가속 보너스로 쓰이던 교육/친밀도 항목은 엔진에서 제외. 경주 중 가벼운 거부/강한 거부는 **출발 지연·초기 체력 낭비**로 나타난다. 미설정 기질/기수 관계는 반영하지 않는다. 플레이어 전적/자금 계산과 NPC 경주 계산은 기존 엔진을 사용한다.
- 기존 `horse_ranch_v193` 저장 키, 코어 경주·시장·NPC 시스템은 유지. 교육 탭 초기화 순서 문제에 대한 경량 폴백도 포함.
