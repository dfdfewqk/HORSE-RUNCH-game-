# HORSE RANCH — 합의된 건강 약점·치료·재활 연결 (후속 PR)

## 적용 기준
- 기존 말 프로필의 `단점`을 그대로 사용하며 대표 단점은 최대 두 개로 제한. 별도 건강 능력치/수동 치료 UI를 추가하지 않는다.
- 부모의 **확인된** 건강 취약성을 자마의 *숨은 가족력 후보*로만 보존한다. 혈통만으로 취약성을 확정하거나 모두 공개하지 않는다. 관찰 기록으로 확인한 취약성만 기존 단점 목록에 표시한다.
- 기본 사육, 일상 조교, 부상 치료 및 재활은 직원/수의사가 자동 처리한다. 추가 클릭은 요구하지 않는다.
- 실제 외부 진단이 있을 때에만 `hrRecordVeterinaryCase(horseId, caseData)`로 치료를 시작할 수 있다. `caseData`에는 진단 종류, 중증도, 치료/재활/조교복귀 기간이 필수이며, 중증은 수의사가 판정한 경주 복귀 가능 여부가 필수다.
- 부상 중 출전 등록이 취소되고 출전/자동 조교가 차단된다. 3단계 치료→재활→조교 복귀 준비가 달력 날짜에 따라 자동 완료되며 완료 시 기록에 남는다. 중증이라도 수의사가 복귀 가능하다고 판단하면 자동 은퇴하지 않는다.
- 경주 복귀가 의학적으로 불가한 경우에만 기존 은퇴 진로 결정 대기열로 연동한다. 플레이어에게 치료 단계별 결정을 강요하지 않는다.
- 기존 `injury` 값이 양수인 저장은 해당 *남은 회복일* 정보만 자동 인계하며 정확한 부상 종류/과거 경력을 지어내지 않는다. 기존 말/경주/저장 키를 유지한다.

## 아직 구현하지 않은 것 — 의도적
- **부상 발생 난수 추첨, 부상 위험 배율, 유전 확률 및 유전적 약점에 의한 수치상 재활 차이:** 아직 확정되지 않아 추가하지 않음.
- 수의사 진단을 대신하는 임의 AI 판정, 중증 부상의 자동 안락사, 각 부상 종류의 임의 치료기간.
- 일상 건강 전용 화면, 새로운 교육·훈련 관리 버튼, 외형·디자인 변경.
- 1/7/30일 중단 및 은퇴 진로 처리 기능은 부모 PR #6(`work/hr-agreed-life-decisions-20261026`)이 선행 조건. 번식·방목지 PR #4는 별도 작업.
