# HORSE RANCH 20.10 — 시장·특별 경매 1차 구현과 검증

## 결정된 게임 규칙

- 일반 시장: 게임 날짜마다 NPC 소유 경주마 **최대 5마리** 노출. 실제 NPC가 보유한 말만 판매, 구매 시 소유권 변경.
- 게임 첫날을 **월요일**로 간주하고 이후 날짜를 7일 주기로 연결. 날짜는 30일×12개월=360일 기준이므로 실제 달력과는 무관.
- 금요일 특별 경매: **목장 종합 랭킹 상위 5위 이내** 목장만 출품 가능. 출품은 원래부터 상위권에만 고정된 NPC가 아니라 경주 성적에 따라 동적으로 결정.
- 종합 랭킹: 각 목장의 현역마 상위 3마리의 능력·레이팅·최근 1년 성적을 사용하고 자산은 반영하지 않음. 게임 밸런스용 초기 공식.
- 상위권 NPC의 실제 보유마 중 매주 최대 **5마리** 출품. 상위권에 진입한 플레이어는 **금요일마다 최대 1마리 추가 출품**.
- 플레이어 출품 전제: 2세 이상 현역, 임신 중이거나 출전 등록 중이지 않은 말. 출품 시 기존 마방에서 바로 제외하지 않음.
- 낙찰되지 않으면 판매 취소 및 소유권 유지. 낙찰 시에만 말 소유권 이동·게임 자금 정산.
- 플레이어는 NPC 출품마에 입찰 가능. 첫 입찰은 최저가, 그 이후 50만원 단위 증가. 경매 종료는 토요일로 넘어가는 시점. 동시에 입찰한 게임머니는 중복으로 사용할 수 없게 계산.
- NPC 경쟁 입찰은 기존 NPC 경제 모델이 아직 미완성이어서 게임 내 단순 가격 모델을 사용함. 가격·랭킹 가중치는 이후 플레이테스트로 조정.
- 기존 `horse_ranch_v193` 저장 키와 다른 시스템 파일은 수정하지 않음. 장기 저장에는 `state.ranchAuction`만 추가.

## 변경 파일

- `index.html`: 20.10 JS 2개 script 태그 로드 추가만 수행.
- `systems/ranch-auction.js`: 순위, 시장 목록, 경매 생성·입찰·출품·정산·중복 방지.
- `systems/ranch-auction-integration.js`: 기존 게임 UI/날짜/저장/소유권과 통합.
- `tests/ranch_auction.test.cjs`: 금요일 판정, 순위 변동, 출품 자격, 주 1회, 낙찰 후 중복 정산 방지, 동일 이름 목장.

## 검증

- `node --check` 신규 두 JS 모듈 및 메인 HTML inline script: 통과.
- `node tests/ranch_auction.test.cjs`: 통과.
- 기존 20.3~20.9 테스트 7종: 통과.
- Chromium에서 새 게임 코드 구성, 상위권 진입, 게임 내 금요일 진입, NPC 출품 5마리 확인, 플레이어 1마리 출품, 입찰, 토요일 정산, 총 6건의 결과 기록, 소유권 중복 없음: 통과.
- 실제 Windows에서 원격 GitHub Pages를 열어 작동하는지 및 장기 경제 밸런스는 별도 확인 필요.

- 경매 상세 경쟁 UI, 플레이어의 시작가 직접 입력, 입찰 취소 규칙, 목장 평판과 경주 성적의 가중치 조율, 거래 수수료, NPC 예산 집행/경매 투자 로직, 수용량 100마리 확장 시스템.
