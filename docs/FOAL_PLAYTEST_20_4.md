# HORSE RANCH 20.4 — 번식·망아지 교육 연결 1차 검증

20.3 main 8339e506192aa897d2e1846a4d452146fbba2be7 기준의 점진적 개발.

## 기능
- 교배 → 300일 후 출산 → 0~1세 어린 말 기초교육 → 2세 성마 성격 고정 → 성마 훈련 → 경주 참가.
- 0세 기본 능력, 유전적 잠재력, 성장 효율 구분. 부모 ID 보존.
- 망아지 교육: 지시·환경 적응, 1세부터 출발·주행 기초. 수동·자동 선택, 월 3포인트.
- 성마 훈련: 잠재력 한계에 가까울수록 성장 실패 가능성이 증가.
- 학습된 교육 수치가 성마 경주 속도에 아주 작은 영향을 줌.
- 교육/조교 비용을 월말 통합 청구. 미납 시 임의 말 자동 판매는 하지 않음.
- 30일 진행 버튼 추가. 기존 저장 키 horse_ranch_v193 및 경주 연동 유지.
- 구형 혈통권 소모 제한을 비활성화해 세대를 이어 교배 테스트 가능.

## 시험용 수치
교육 3포인트/월, 기초 교육 숙련도 최대 70, 교육 25,000원/회, 성마 조교 75,000원/회는 미확정이며 최종 밸런스가 아님.

## 검증
- 기존 경주 엔진 단위 테스트 통과.
- 신규 교육·나이·훈련·월말 비용 계산 단위 테스트 통과.
- Chromium / Playwright: 첫 경주·암말 선택 → 교배 → 출산 → 기초교육 → 성마 → 훈련 → 경주 → 저장 복원까지 실행, 점검 중 JS 오류 0건.
- 테스트 환경에서 file:// 접근이 차단되어 HTML에 스크립트를 인라인 주입한 동등 소스 테스트. 실제 배포 페이지 실사용 검사는 별도 필요.

## 미완성
부모·조부모 혈통 중복 페널티, 능력별 잠재력 상충, NPC 5개 목장의 경영, 말 폐사 및 나이별 은퇴, G1·G2 레이팅 출전, 금요일 특별 경매는 구현하지 않음.
기존 8세 자동 은퇴는 아직 구형 규칙.
